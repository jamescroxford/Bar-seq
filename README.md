This repository supplements the thesis Barcodes and bioreactors: Exploring strain stability and genome dynamics in *Streptomyces clavuligerus*.  

It contains:
- Code for identifying barcode sequences within mixed pools of barcodes (Section 3.5).  
- Data and scripts related to Section 5.4, covering the detection of possible chromosome circularisation in *S. clavuligerus* SC6.
